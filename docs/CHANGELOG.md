# 変更履歴

## 1.1.0 — 2026-11-03
- 日本語・ベトナム語・英語に対応。ヘッダーに言語選択（地球儀ボタン）を追加。画面の文言は `src/i18n.js`、タイトル・説明は `site.config.json` の `i18n`。選んだ言語は保存せず、URLの `#ja` `#vi` `#en` とブラウザの言語設定で決める。
- 点数の単位（点／điểm／pts）と除外メッセージも言語に合わせて切り替え。書き出し画像の単位も同様。
- 狭い画面（≤760px）では言語ボタンをアイコンのみにし、ロゴを幅に合わせて縮める（360×640で横にはみ出さない）。
- Noto Sans に weight 400 を追加（ベトナム語・英語の本文用）。
- テスト: `tests/i18n.test.mjs`（三言語のキー一致・body.html との整合など）を追加。画面チェックを3言語×6サイズに拡張し、言語切り替えも確認。
- ベトナム語・英語の文言は Claude による下訳（ネイティブ確認前）。
- 重なる文字の色の選択肢「全部黒字」を「黒文字」に変更（ベトナム語 Chữ đen、英語 Black text）。
- ルール説明ダイアログの「閉じる」ボタンを下に固定（文言が長く、内側がスクロールする画面でも見える）。
- 入力したティッカーをこのブラウザの中（localStorage）に保存し、次回も復元（空にすると消える）。プライバシー文を「保存しません」から「入力した銘柄コードだけブラウザに保存」へ直し、e2eに保持テストを追加。
- プライバシー文を具体化: Google Fonts と Cloudflare（配信）には通信が届くこと、Cloudflare にアクセスの記録が残ることがあること、入力内容は通信に含まれないことを明記。その後、文章を短く平易に整えた（意味は同じ）。
