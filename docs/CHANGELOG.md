# 変更履歴

## 1.1.0 — 2026-11-03
- 日本語・ベトナム語・英語に対応。ヘッダーに言語選択（地球儀ボタン）を追加。画面の文言は `src/i18n.js`、タイトル・説明は `site.config.json` の `i18n`。選んだ言語は保存せず、URLの `#ja` `#vi` `#en` とブラウザの言語設定で決める。
- 点数の単位（点／điểm／pts）と除外メッセージも言語に合わせて切り替え。書き出し画像の単位も同様。
- 狭い画面（≤760px）では言語ボタンをアイコンのみにし、ロゴを幅に合わせて縮める（360×640で横にはみ出さない）。
- Noto Sans に weight 400 を追加（ベトナム語・英語の本文用）。
- テスト: `tests/i18n.test.mjs`（三言語のキー一致・body.html との整合など）を追加。画面チェックを3言語×6サイズに拡張し、言語切り替えも確認。
- ベトナム語・英語の文言は Claude による下訳（ネイティブ確認前）。
- 重なる文字の色の選択肢「全部黒字」を「黒文字」に変更（ベトナム語 Chữ đen、英語 Black text）。
- ルール説明ダイアログの「閉じる」ボタンを下に固定（文言が長く、内側がスクロールする画面でも見える）。
- 総合スコア: ほかの銘柄と共通する文字が1つもない銘柄（組み合わせられない銘柄）は、上限でも満点を取れたものとして数えるようにした。混ざっているほどスコアが下がる（初期10銘柄 78 → +ONE 70 → +ONE・AAA 64）。孤立銘柄がなければ従来と同じ。1銘柄だけ・全銘柄が孤立のときは「採点できません」ではなく0点になる。採点の説明文（3言語）、SPEC、テストを更新。
- タグラインを「ベトナム株のティッカーを楽しく見せ合おう」に変更（「パズル」をやめた。ベトナム語 Cùng nhau khoe mã cổ phiếu Việt Nam thật vui、英語 Have fun showing off your Vietnamese stock tickers）。ページのタイトル・説明・空表示の文言・README・SPEC・共有用画像 og.png（`scripts/og-tagline.py` で差し替え）も合わせた。
- タグラインが2行に折れるとき、「…見せ合お／う」のように1文字だけ残らないよう、文節で折り返し・行の長さをそろえる（`word-break: auto-phrase; text-wrap: balance`）。
- 右の銘柄チップの枠線を削除し、塗りのみにした（選択中は青の塗り。「配置されない銘柄」の破線は薄く表示に変更）。
- 入力欄を最初から2行ぶんの高さで固定し（3行以上は中でスクロール）、上端を再配置ボタンにそろえた。入力が増えても枠が動かない。
- 入力中にスペースや入力途中の文字だけが変わったときは、盤面を描き直さない（ちらつき防止）。銘柄か配置パターンが変わったときだけ描き直す。
- 除外メッセージの場所を最初から2行ぶん確保し、入力中にメッセージが出ても画面が動かないようにした（3行以上は中でスクロール）。e2eに追加。
- 利用規約（terms.html）とプライバシーポリシー（privacy.html）を追加（日本語のみ。構成は運営者の別サイト EZO HAZEL PLANTNER の規約に合わせた）。「採点のしくみ」ダイアログに両ページへのリンクを追加（Artifact版には入れない）。運営者名・連絡先・管轄裁判所は `site.config.json` の `operator`。
- 入力したティッカーをこのブラウザの中（localStorage）に保存し、次回も復元（空にすると消える）。プライバシー文を「保存しません」から「入力した銘柄コードだけブラウザに保存」へ直し、e2eに保持テストを追加。
- プライバシー文を具体化: Google Fonts と Cloudflare（配信）には通信が届くこと、Cloudflare にアクセスの記録が残ることがあること、入力内容は通信に含まれないことを明記。その後、文章を短く平易に整えた（意味は同じ）。

## これまでの主な変更（Artifact v1〜v27）
- ロゴを左上に配置し、英語＋カタカナのバイリンガルロゴに差し替え（書き出しにも反映）。
- 点数の数字に色を付与（背景なし、太さ一定）。点数横の★を削除。
- 画像保存: 点数のON/OFF（既定OFF）、ファイル名に日時、ロゴ下に余白。
- 重なる文字の色の選択肢「先の色」→「単色」に変更。
- タグライン「ベトナム株のティッカーをパズルにできる」に整理。入力欄に黒い枠線。
- 公開サイト化（Cloudflare Pages）、OGP・ファビコン・セキュリティヘッダ追加。CSP下で動く通常ダウンロードのフォールバック。
- 狭い画面（360×640）での枠とヘッダーの重なりを修正。
- ティッカー一覧を Vietstock の1,519件に更新。
- セキュリティ強化: CSP から `'unsafe-inline'` を除去しインラインの script/style を SHA-256 ハッシュで許可（ビルドが `_headers` を生成）。`style` 属性を廃止（CSSOM へ）。COOP/CORP/HSTS 追加、`security.txt`・`robots.txt` 追加、`npm run test:csp`（本番と同じヘッダーで実ブラウザ検査）。
- アクセス解析: Cloudflare Web Analytics（Pages の自動挿入）を導入。CSP に cloudflareinsights を許可、プライバシーポリシー（改定日 2026年11月4日）・アプリ内の説明（ja/vi/en）・外部送信の公表表を更新。
