Crosstick（クロスティック）（以下「本サイト」）は、ベトナム株のティッカーコードを図にして画像で保存できる、無料のウェブツールです。運営者 {{OPERATOR}}（以下「運営者」）は、利用者のプライバシーを大切にするため、本サイトで扱う情報を次のとおり定めます。

1. 基本方針

利用者が入力したティッカーコードや、作った図は、運営者に送られません。 利用者自身のブラウザの中だけで処理し、保存します。

本サイトには、ログイン・会員登録・広告・追跡用の Cookie はありません。アクセス状況の把握には Cloudflare Web Analytics を使います（3 を参照）。運営者が受け取る情報は、3 に書いたものだけです。

2. ブラウザの中に保存される情報

次の情報は、お使いの端末のブラウザ（localStorage）にだけ保存され、運営者のサーバーには送られません。

  • 入力したティッカーコード（次に開いたときに入力し直さなくてよいように。最大600文字。キー名 crosstick:tickers）

表示言語、見た目の設定、点数の結果は保存しません。「画像を保存」で書き出した画像は、利用者の端末の中で作られ、利用者が自分で保存・管理するものです。

保存した内容は、入力欄を空にすると消えます。ブラウザのデータを消す、端末を替える、ブラウザを入れ直すなどでも失われます。ブラウザのサイトデータを消すと、保存された情報をすべて消せます。共用の端末では、保存した内容が次に使う人にも表示されることがあるので、使い終わったら入力欄を空にしてください。

3. 運営者が受け取る情報

アクセスログ：本サイトは Cloudflare Pages で配信しています。Cloudflare が、配信と安全のために標準のアクセスログ（IP アドレス、閲覧したページ、日時、ブラウザの種類など）を記録することがあります。運営者は、これを個別の利用者を特定する目的では使いません。

アクセス解析：本サイトは、利用状況（閲覧数、アクセス元の国、参照元、端末やブラウザの種類、表示速度など）を集計するため、Cloudflare の Cloudflare Web Analytics を使っています。運営者が見るのは集計された統計で、個別の利用者を特定する目的では使いません。入力したティッカーコードや結果は、集計の対象に含まれません。

お問い合わせの情報（個人情報）：{{CONTACT_CHANNEL}}でお問い合わせいただいたときは、アカウント名と、お問い合わせの内容をお預かりします。これらは個人情報にあたることがあります。ご返信と対応の記録のためだけに使い、個人情報保護法にしたがって、大切に取り扱います。ご本人の同意がある場合や法令にもとづく場合を除き、この目的以外に使ったり、第三者に渡したりすることはありません。

5. 外部サービスへの情報の送信（外部送信に関する公表）

本サイトを使うと、お使いのブラウザから次の外部サービスへ直接通信します。このとき、各サービスに IP アドレスとブラウザの情報が届きます。入力したティッカーコードや結果は、この通信に含まれません。運営者が受け取るのは、Cloudflare Web Analytics の集計結果だけです。取り扱いは、各社の方針をご覧ください。

送信先（サービス）送信される情報目的
Cloudflare Web Analytics（static.cloudflareinsights.com、cloudflareinsights.com）IP アドレス、ブラウザの情報、閲覧したページ、参照元、表示速度利用状況の集計
Google Fonts（fonts.googleapis.com、fonts.gstatic.com）IP アドレス、ブラウザの情報文字（フォント）の表示

なお、本サイトの配信元である Cloudflare には、3 のとおり、アクセスの記録が残ることがあります。ブラウザの設定でフォントの通信を止めることもできますが、その場合、文字の表示が変わることがあります。

6. Cookie と localStorage

本サイトは、Cookie を設定しません。localStorage は、上の 2 の情報を利用者のブラウザに保存するためだけに使います。
